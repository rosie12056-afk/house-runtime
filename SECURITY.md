# Security

The alpha release is a local runtime library and demo. It is not an authenticated public server and must not be exposed directly to a network.

Artifact paths are constrained to the configured workspace. Context Manifests contain references rather than source bodies. Adapter proposals and runtime state may contain private text in a real instance, so database and workspace permissions remain the deployer's responsibility.

Do not include production data in an issue. Use GitHub private vulnerability reporting when available.
